## Como usar estes cronogramas

As durações abaixo são estimativas realistas para uma pessoa **autodidata dedicada**, considerando estudo teórico + prática + exercícios + projetos de cada fase — não apenas "assistir aula". Ajuste conforme seu ritmo real; o objetivo é o **critério de conclusão de cada fase**, não a data exata.

## Observações válidas para os três cronogramas

- **Fases 13, 14 e 15 podem (e devem) se sobrepor no fim** — você pode começar a aplicar para vagas Junior enquanto ainda finaliza o último projeto do portfólio, especialmente porque o processo seletivo em si (da triagem à proposta) frequentemente leva de 3 a 8 semanas.
- **Revisões via Spaced Repetition (Fase 0) rodam em paralelo, o tempo todo** — não estão contabilizadas como "fase" separada porque são um hábito contínuo, não uma etapa finita.
- Se você perceber que uma fase está demorando significativamente mais que o estimado, isso não é necessariamente um problema — pode indicar que você está aprofundando mais que o mínimo (o que é positivo), mas vale revisar se não é procrastinação disfarçada de "preciso estudar mais antes de avançar" (ver Erros Comuns da Fase 0 — "tutorial hell").
