## 📌 Sobre este repositório

Este repositório é o **hub central** do meu Projeto de Desenvolvimento Autodidata como Software Engineer: aqui documento tudo que estudo, registro decisões técnicas e mantenho o rastreador de progresso da trilha, partindo de uma transição de carreira do **Design Gráfico e Branding** para minha primeira oportunidade como **Software Engineer Junior/Estagiária**. Cada **projeto de portfólio** vive no seu próprio repositório (linkado na tabela abaixo) — este `software-engineer` é o "índice vivo" que amarra tudo.

A trilha está estruturada em **16 fases + 6 anexos**, cobrindo desde fundamentos de computação até arquitetura, segurança, cloud, uma trilha complementar em Java/Spring Boot e uma rotina contínua de prática deliberada (LeetCode e afins) — equivalente, em profundidade, a uma formação sólida de Ciência da Computação aplicada ao mercado de 2026/2027. Sobre essa base, corre uma **camada própria de Design Engineering** (Anexo F) — a ponte entre minha bagagem em Design Gráfico e a engenharia de produto, construída desde a primeira fase em vez de deixada como um adendo de última hora.

> 💡 Sinta-se à vontade para navegar pelos arquivos, abrir os PRs antigos e ver a evolução — este repositório existe justamente para ser um histórico honesto de aprendizado, erros incluídos.

---

## 🎯 Objetivos

- Conquistar minha primeira vaga de **Estágio/Trainee em Software Engineering** no mercado do **Rio de Janeiro**
- Construir uma base sólida em **Node.js/TypeScript + React**, com Java/Spring Boot como stack poliglota complementar
- Diferenciar meu portfólio unindo **engenharia backend-leaning** com profundidade real em **Design Engineering** — não como discurso, mas como código e sistema documentados
- Documentar o processo publicamente, com honestidade sobre o que ainda não sei
