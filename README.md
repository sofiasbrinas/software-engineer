## 📌 Sobre este repositório

Este repositório é o **hub central** da minha formação como Software Engineer: aqui eu documento tudo que estudo, registro decisões técnicas e mantenho o rastreador de progresso da trilha. Cada **projeto de portfólio** vive no seu próprio repositório (linkado na tabela abaixo) — este `software-engineer` é o "índice vivo" que amarra tudo.

A trilha seguida está estruturada em **16 fases + 4 anexos**, cobrindo desde fundamentos de computação até arquitetura, segurança, cloud e uma trilha complementar em Java/Spring Boot — equivalente, em profundidade, a uma formação sólida de Ciência da Computação aplicada ao mercado de 2026/2027.

> 💡 Sinta-se à vontade para navegar pelas pastas, abrir os PRs antigos e ver a evolução — este repositório existe justamente para ser um histórico honesto de aprendizado, erros incluídos.
